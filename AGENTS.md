# Guide content requirements

Guides must provide the answers and actions needed to finish their steps. Include required
puzzle solutions, dialogue choices, item quantities and sources, NPC/map locations, waits,
zoning and turn-in order. Spoilers are allowed. Include dialogue only when selecting the
correct choice is relevant to completing the step; omit unrelated conversations and lore.

Preserve authored `data/quest_solutions.lua` overrides when regenerating script-derived
walkthroughs. Do not label an omitted answer as a complete walkthrough or infer that an
expansion/job is enabled on a server merely because a reference wiki documents it.
Never test addons on hosted servers.
