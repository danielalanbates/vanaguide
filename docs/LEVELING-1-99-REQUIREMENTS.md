# Server-aware solo progression, target1-99

Latest user scope supersedes the earlier1-25 starter route. Build complete leveling paths from1 to99 where the selected server supports99; respect lower caps such as Horizon75 and distinguish main/legacy realms. Route selection must use verified expansion availability, server customizations, job and relevant unlocks. A level cap alone does not imply expansion availability.

Every combat camp step must provide both: (1) a named EXP monster with zone and verified location; (2) a named gil monster with named valuable drops or a verified NM placeholder/camping opportunity. The same monster may fill both roles only when its EXP and loot reasons are explicit. Include market dependence, travel/safety and job restrictions; never promise fixed gil/hour from an old price. Travel/unlock steps should retain the surrounding camp pair rather than inventing a monster for an administrative action.

The existing Horizon1-25 guide is incomplete against this scope. BST/BLM wiki camp summaries do not constitute universal1-99 coverage. Server capability profiles, structured camp records, level-gap checks, expansion/job filters, native UI and addon integration, content verification and live private-server acceptance are required before claiming completion.

Current official-source review2026-10-30: Horizon homepage advertises75 cap and content through ToAU; Legendary advertises99 and content through Adoulin/Abyssea/add-ons; MistXI lists main75, legacy99 and content through Wings of the Goddess. Preserve these distinctions and source links in the capability data. Unknown servers need explicit unverified capability state rather than a guessed complete route.
