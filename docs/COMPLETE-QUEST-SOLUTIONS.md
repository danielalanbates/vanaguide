# Completion answers and relevant dialogue

The user wants every guide to contain the solutions needed for its steps. Spoilers may be
included. Include only dialogue choices relevant to completion, rather than transcripts or
unrelated story text. Authored additions live in data/quest_solutions.lua so regeneration of
the script-derived quest_steps.lua cannot erase answers that the server scripts do not name.

The BLU unlock overlay replaces the existing An Empty Vessel (ahturhgan/5) walkthrough in
the native quest catalogue, including Job Unlocks. It provides all ten divination choices
as short question-topic/answer cues, the fee and day/zone wait, all three clue/item matches,
collection requirements, Waoud's returned-item behavior, the Bhaflau I-7 entrance, pool H-9,
required final acceptance and follow-up. It contains no cutscene transcript.
