## Bugs found and fixed

| Bug | Effect | Fix |
|---|---|---|
| `tools/guided_run.sh` sent `!delquest` and `!pos` in the same instant | Every cross-zone teleport was dropped; 3/5 steps failed in run 1 | 2 s gap between them |
| cmdpipe `pump()` read `cmd.txt` then truncated it | Any line appended between read and truncate was lost | Rename the file aside, then read (launcher branch `harness-alt-pipe`) |
| Earlier (Codex) attempt: second launch reused the first launch's map session | FFXI binds fixed UDP 54090, so the new client hit the stale session; it timed out 300 s after launch #1 | One launch per fresh server start |

## Gotchas for the next run

- A `/vg pick` (event *update*) on a non-menu cutscene leaves the client in an event; `/shutdown`
  then answers "You cannot use that command at this time." `!release` clears it, then `/shutdown` works.
- The generated guide skips quests the server already marks complete; clear them with
  `!delquest sandoria <id>` and `/vg reset` to run from step 1.
- Harness: `VG_GAME=<lab game dir> VG_NARR=<lab>/tmp/vanavoice/dialogue.jsonl tools/guided_run.sh 11 6 <out>`.
